Thank you for helping. You will see pairs of images made from the same text description by two different methods, and say which one you prefer.

  • Each pair has two views. Whole image shows both images fitted to the screen. Detail (1:1) shows the same region of both at full resolution; drag either image to move both.
  • Please look at both views before answering. The questions unlock once you have opened the detail view.
  • There are two questions per pair: which image you prefer overall, and which has better fine detail. "No difference" is a valid answer.
  • Which method is on the left or right changes randomly from pair to pair. There are no right answers; we want your own judgement.
  • Your answers are saved after every pair. You can close the page and come back to the same link later.
  • Please use a desktop or laptop screen with the browser window maximised and the browser zoom at 100 %.
